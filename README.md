# 🛠️ mod-minecraft

_Mod này được phát triển để **tối ưu hóa** trải nghiệm chơi Minecraft trên **PojavLauncher**._

## 🌟 Tính năng nổi bật

- 🚀 **Tăng hiệu suất:** Tối ưu hóa RAM và CPU để giảm thiểu tình trạng lag.
- 🖥️ **FPS mượt mà:** Đảm bảo FPS ổn định, giúp trải nghiệm chơi game tốt hơn.
- 🌍 **Tải chunk nhanh:** Nâng cao khả năng load các chunk hiệu quả, không bị khựng.

---

## 📦 Hướng dẫn cài đặt

1. **Tải mod về:** Tải bản mod từ kho lưu trữ này.
2. **Thêm vào thư mục `mods`:**
   - Mở cấu hình PojavLauncher.
   - Thêm file mod vào thư mục `mods`.
3. **Khởi chạy:** Mở Minecraft thông qua PojavLauncher và tận hưởng trải nghiệm tối ưu! 🎮
